# 💼 Pratik Haridas Khodwe - Portfolio Website

This is my personal portfolio website built using **Flask**, HTML5, CSS3, and JavaScript.  
It showcases my professional profile, projects, blogs, and contact information — designed with a modern and responsive UI.

🔗 **Live Repo**: [GitHub Repo](https://github.com/Khodwepratik/portfolio)

---

## 🚀 Features

- ⚡ Responsive Design
- 🌙 Dark Mode Toggle
- 🧠 Project & Blog Sections
- 📩 Contact Form (with email integration)
- 📄 Resume Download Button
- 🎨 Animated Transitions

1. **Clone the repository**:

```bash
git clone https://github.com/Khodwepratik/portfolio.git
cd portfolio
Create a virtual environment (optional but recommended):



python -m venv venv
venv\Scripts\activate

pip install -r requirements.txt


Run the app:
python app.py
